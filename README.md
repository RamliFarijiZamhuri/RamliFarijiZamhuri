### 🚀 Core Focus & Kompetensi

*   **Pemrograman Berorientasi Objek:** Mendalami implementasi mendalam **Java OOP**, khususnya dalam membandingkan keunggulan *Inheritance* vs *Composition*.
*   **Analisis & Pemodelan Sistem:** Menguasai pendekatan struktur sistem menggunakan **Soft Systems Methodology (SSM)**, **CATWOE Analysis**, serta dokumentasi alur bisnis berbasis **BPMN** dan *Activity Diagram*.
*   **Arsitektur & Desain Data:** Merancang skema database yang optimal melalui proses **Normalisasi** bertingkat dan pemodelan **ERD (Crow's Foot Notation)** menggunakan Draw.io.
*   **Infrastruktur Jaringan & Cloud:** Mempelajari model **OSI & TCP/IP**, keamanan jaringan, serta perencanaan **Cloud Architecture** (analisis biaya TCO, CapEx vs OpEx, skema IaaS/PaaS, SLA, dan regulasi privasi data lokal).

### 📌 Featured Project

#### 🏛️ Sistem Registrasi Organisasi Mahasiswa (ORMAWA)
*Sebuah studi kasus perancangan struktural komprehensif untuk sistem pendaftaran organisasi kemahasiswaan.*
*   **Analisis Aturan Bisnis:** Menggunakan *CATWOE* untuk memetakan transformasi kebutuhan *stakeholder*.
*   **Cetak Biru Data:** Menyusun arsitektur database yang ternormalisasi penuh menggunakan diagram *Crow's Foot* di Draw.io untuk mencegah redundansi data pendaftar.
*   **Alur Proses:** Visualisasi alur kerja panitia dan mahasiswa menggunakan standar notasi *BPMN*.
